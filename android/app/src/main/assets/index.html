For full control (mute the mic hardware, one app, or only RDP), run RemoteMic.exe on the laptop. Scan its QR code with the phone camera and tap open in app, or paste its link here. Same keys, same flow.
key mapedit shortcuts
Write keys like ctrl+shift+m, win+alt+k, ctrl+space. Modifiers: ctrl, shift, alt, win.
how it worksread once
The phone pairs with the laptop as a Bluetooth keyboard, so Windows needs no app.

call mute · win+alt+k: Windows 11 mutes or unmutes Teams calls from any window. Teams shows the change.
teams · ctrl+shift+m and meet · ctrl+d go to whatever window is in front. For an RDP call, keep the Remote Desktop window in front and Teams in front inside it.
push to talk: Teams mode holds Ctrl+Space (stay muted in Teams first). Win11 mode sends win+alt+k when you press and again when you let go.

Bluetooth can't mute the microphone hardware or a single app. That still needs the Wi-Fi agent (RemoteMic.exe).
Preview only. Install the Remote Mic APK on your phone to send keys over Bluetooth.
